# 🌈 Mood Tracker

A simple and aesthetic web app to track your daily mood.

## ✨ Features
- Select mood with emojis
- Add a daily note
- Save moods using localStorage
- View mood history
- Clean & aesthetic UI

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript
